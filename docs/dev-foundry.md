# Dev-стенд Foundry

Нативный Foundry использует свой User Data, отдельно от staging в Podman.
В текущей установке адрес — `http://127.0.0.1:30000`, мир — `ouw25test`,
User Data — `~/Library/Application Support/FoundryVTT`.

## Устройство

`npm run dev:prepare` создаёт игнорируемый Git каталог `dist/dev/ouw25`.
В нём отдельный `system.json` без URL обновления релиза и ссылки на исходные
`module`, `templates`, `styles` и `lang`. Каталог
`<User Data>/Data/systems/ouw25` ссылается на этот Dev-пакет. Поэтому все миры
нативного Foundry на системе `ouw25`, включая `ouw25test`, используют текущие
исходники, в том числе незакоммиченные изменения. Это не изолирует мир от
изменений схемы и игровых данных: перед рискованными изменениями создавайте
резервную копию мира.

В настройках нативного сервера включён `hotReload`; в Dev-манифесте он включён
для CSS, HBS и локализаций. Foundry следит за файлами при запущенном мире и
перерисовывает открытые приложения. Изменения JavaScript требуют перезагрузки
страницы клиента; изменения серверной конфигурации и типов документов могут
потребовать перезапуска мира или Foundry. Изменения `system.json` надо сначала
перенести в Dev-манифест повторным `npm run dev:prepare` и перезапустить мир.
Изображения и шрифты могут кешироваться клиентом.

Не обновляйте и не удаляйте Dev-систему через менеджер пакетов Foundry: это
может нарушить связь с исходниками. Для проверки опубликованного релиза
используйте отдельный staging, а не этот Dev-пакет. `npm run build`,
`npm test` и `npm run package` продолжают использовать `dist/ouw25`, независимо
от Dev-пакета.

## Восстановление и перенос

После перемещения репозитория заново создайте Dev-пакет в новом расположении и
обновите ссылку `Data/systems/ouw25` при остановленном Foundry. Скрипт не
заменяет существующие каталоги или ссылки на другие исходники внутри Dev-пакета.

Перед первоначальным подключением сохранены исходный пакет, мир и настройки в
`~/Library/Application Support/FoundryVTT/Backups/ouw25-dev-setup-20261126-0407`.
Чтобы вернуться к прежнему пакету, остановите Foundry, удалите только ссылку
`Data/systems/ouw25` и скопируйте сохранённый каталог `ouw25-system` на её
место. Копия мира представляет состояние на момент подключения; не
восстанавливайте её поверх новых игровых данных без отдельного решения.
Настройку `hotReload` можно отключить в настройках Foundry.
