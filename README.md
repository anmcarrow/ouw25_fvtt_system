# «Укрытое море: Благословенный прилив» — Foundry VTT System

Ранняя сборка самостоятельной системы `ouw25` для Foundry VTT v14. В ней есть два типа Actor — «Коммерсант» и «Кооператив», листы заметок, карманные деньги, пенсионный счёт, бюджет и проверка (не)удачи с выводом костей и итога в чат. Пенсионный взнос подтверждается отдельно и не списывается с других счетов. Для судна реализованы расчёт рейса, подтверждаемый переход с откатом, сброс счётчиков, психотерапия и увеличение смуты. Драматический размен ещё не перенесён. Контент будет отдельным пакетом.

В Foundry откройте **Game Systems → Install System** и вставьте URL манифеста: `https://github.com/anmcarrow/ouw25_fvtt_system/releases/latest/download/system.json`. После установки создайте тестовый мир на системе «Укрытое море: Благословенный прилив».

## Локальная установка

1. Выполнить `npm run build`. Сборка не требует внешних npm-зависимостей.
2. Скопировать `dist/ouw25` в каталог `<Foundry User Data>/Data/systems/`, чтобы `system.json` оказался в `Data/systems/ouw25/system.json`.
3. Перезапустить Foundry и создать отдельный тестовый мир, выбрав систему «Укрытое море: Благословенный прилив». Не подключать каркас к боевому миру.
4. Создать Actor каждого типа, сохранить заметку и открыть лист заново. Для многопользовательской проверки назначить одному игроку `Owner`, другому — `Observer`.

`npm test` проверяет сборку, расчёты и операции рейса в тестовом окружении Node.js; это не заменяет проверку в живом мире. `npm run package` собирает архив `dist/ouw25.zip` для установки Foundry; для команды нужен `zip`.
